# Robot Marketplace

A modern, aesthetic web platform for renting and selling robots. Connect with robotics enthusiasts and access cutting-edge robotic equipment for training, research, and innovation.

## Features

- **User Authentication**: Sign up and login system
- **Robot Listings**: Browse available robots for rent or purchase
- **List Your Robot**: Easy form to add your own robots to the marketplace
- **Delivery Options**: Choose between pickup and delivery
- **Modern UI**: Beautiful, responsive design with smooth animations

## Getting Started

Simply open `index.html` in your web browser to view the website. No build process or server required!

## Pre-loaded Robots

1. **SO-101 Robotic Arm** - Perfect for robot training ($89.99/day)
2. **Unitree Go2 Quadruped** - Advanced quadruped robot ($199.99/day)

Both robots are available for rent with pickup and delivery options.

## Usage

1. **Browse Robots**: Scroll to the "Featured Robots" section to see available listings
2. **Sign Up**: Click "Sign Up" to create an account
3. **List Your Robot**: After signing up, use the "List Your Robot" form to add new robots
4. **Rent/Buy**: Click "Rent Now" or "Buy Now" on any robot card

## Technologies

- HTML5
- CSS3 (with modern gradients and animations)
- Vanilla JavaScript
- LocalStorage for user session management

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge).
